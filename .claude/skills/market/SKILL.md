# /market — 市场行情速查

用户想了解一个或多个资产的近期表现时，按以下流程操作。

## 判断意图

用户的问法通常分两类：

1. **行情查询** — "沪深300最近一周/一个月/一年行情"、"黄金最近走势"
2. **指标分析** — "纳斯达克和标普谁表现好"、"这几个资产波动率多少"

行情查询用 `get_index_data`，指标分析用 `calc_metrics`。如果用户问的比较笼统（"最近表现怎么样"），两个都调。

## 执行步骤

### 单资产查询

1. 调用 `get_index_data`，根据用户提到的时间范围设置 start_date/end_date
   - "最近一周" → 7天前到今天
   - "最近一个月" → 30天前
   - "最近一年" → 365天前
   - 没说时间 → 默认最近一个月
   - 如果用户想看详细走势，fields 加上 open/high/low/volume
2. 用表格展示每日数据（如果超过 10 个交易日，只展示关键节点或摘要）
3. 总结区间涨跌幅、波动率、最新价

### 多资产对比

1. 对每个资产并行调用 `calc_metrics`，period 根据用户意图选择
2. 用对比表格展示：年化收益、年化波动、Sharpe、Sortino、最大回撤、Calmar
3. 如果用户提到了基准（"跟沪深300比"），在 calc_metrics 中设置 benchmark 参数
4. 给出简短的对比结论

### 支持的资产

直接使用中文名或英文缩写即可，系统会自动识别：

- A股：上证50、沪深300、中证500、中证2000
- 港股：恒生指数、恒生科技
- 美股：纳斯达克100(NDX)、标普500(SPX)、道琼斯(DJI)
- 欧股：DAX
- 债券：中国10年国债
- 商品：黄金(GOLD)
- 货币：美元指数(DXY)

## 输出风格

- 数据用 markdown 表格，保留 2-4 位小数
- 百分比用 % 显示（如 +17.48%），涨用正号，跌用负号
- 结尾给一段 2-3 句的走势特征总结，不做投资建议
