# Voyage v0.1.0 设计文档

> 基准版本，2026-03-09 创建。后续迭代在本目录追加版本记录。

## 一、定位

个人投资组合管理工具，以 MCP Server 形式封装，Claude Code 作为 Agent 直接调用。
聚焦全球多资产指数级别的组合管理与策略分析。

## 二、系统架构

```
用户 ↔ Claude Code (CLI Agent)
              │
              ├── MCP Server: voyage-invest
              │   ├── get_index_data        — 获取指数行情
              │   ├── optimize_portfolio    — 组合优化
              │   ├── run_backtest          — 策略回测
              │   ├── calc_metrics          — 风险收益指标
              │   └── correlation_matrix    — 资产相关性
              │
              ├── 底层库
              │   ├── AkShare       (A股/H股/宏观数据)
              │   ├── yfinance      (美股/欧股/黄金/债券)
              │   ├── Riskfolio-Lib (组合优化引擎)
              │   └── vectorbt      (向量化回测)
              │
              └── 数据存储
                  ├── Parquet 文件  (市场行情数据)
                  └── JSON 文件     (用户偏好，MVP阶段)
```

## 四、MCP Tools 接口规格

### 4.1 get_index_data

获取指数历史行情，自动路由数据源，带 Parquet 缓存。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| index | str | 是 | 指数名称/代码，支持中英文模糊匹配 |
| start_date | str | 是 | 起始日期 YYYY-MM-DD |
| end_date | str | 否 | 结束日期，默认今天 |
| fields | list[str] | 否 | 默认 ["close"]，可选 open/high/low/volume |

返回：时序数据 + 摘要（区间涨跌幅、年化波动率、最新收盘价）。

### 4.2 optimize_portfolio

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| assets | list[str] | 是 | 资产名称列表 |
| method | str | 否 | risk_parity / mvo / hrp / equal_weight |
| risk_free_rate | float | 否 | 默认 0.02 |
| lookback_days | int | 否 | 默认 252 |
| constraints | dict | 否 | {max_weight, min_weight} |

返回：各资产权重 + 组合预期收益率/波动率/夏普。

### 4.3 run_backtest

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| weights | dict[str,float] | 是 | 资产权重 |
| start_date | str | 是 | 回测起始 |
| end_date | str | 是 | 回测结束 |
| rebalance | str | 否 | monthly/quarterly/yearly/none |
| initial_capital | float | 否 | 默认 1,000,000 |
| transaction_cost | float | 否 | 默认 0.001 |
| benchmark | str | 否 | 基准指数名称 |

返回：净值曲线、绩效指标、调仓记录、基准对比。

### 4.4 calc_metrics

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| targets | list[str] | 是 | 资产名称列表 |
| period | str | 否 | 1y/3y/5y/ytd/max |
| benchmark | str | 否 | 基准指数 |
| risk_free_rate | float | 否 | 默认 0.02 |

返回：Sharpe / Sortino / MaxDD / 年化收益 / 年化波动 / Calmar / Alpha / Beta / IR。

### 4.5 correlation_matrix

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| assets | list[str] | 是 | 资产名称列表 |
| period | str | 否 | 1y/3y/5y |
| method | str | 否 | pearson/spearman |

返回：相关性矩阵 + 高/低相关资产对提示。

## 六、数据层设计

### 缓存策略

- 格式：Parquet，存储在 `data/` 目录
- 命名：`{source}_{code}_daily.parquet`
- 增量更新：每次请求检查本地最新日期，只拉取缺失部分，合并去重后写回同一文件
- 始终保持单文件完整数据，不会产生多份碎片

### 名称解析

内置 `_ALIASES` 表支持中英文模糊匹配。解析失败时返回候选列表。

## 七、计算引擎

### 指标计算 (indicators.py)
- annualized_return / annualized_volatility
- sharpe_ratio / sortino_ratio
- max_drawdown / calmar_ratio
- alpha / beta / information_ratio

### 组合优化 (portfolio.py)
- equal_weight：等权
- risk_parity：风险平价（Riskfolio-Lib）
- mean_variance：均值方差最大夏普（Riskfolio-Lib）
- hierarchical_risk_parity：层次风险平价（Riskfolio-Lib）
- _apply_constraints：迭代冻结式权重约束

### 回测 (backtester.py)
- 按日模拟，支持 monthly/quarterly/yearly/none 调仓
- 扣除交易成本（按 turnover × cost_rate）
- 输出净值曲线、绩效指标、调仓日志

### 事件研究辅助 (event_helpers.py)

不是 MCP tool，而是供 Claude Code 动态生成的 Python 脚本 import 的通用函数库。

- `load_prices(asset_name)`：名称解析 → 读 Parquet 缓存 → 返回 close Series
- `post_event_returns(prices, event_dates, holding_period)`：计算事件后 N 个交易日收益率
- `return_stats(returns)`：收益分布统计（均值/中位/胜率/分位数/标准差）
- `benchmark_comparison(asset_returns, benchmark_returns)`：超额收益 + 单样本 t 检验
- `decluster(event_dates, all_dates, min_gap)`：贪心去聚集，避免重叠持有期

设计动机：事件条件是无限的（涨跌幅、均线交叉、量价背离...），不可能穷举为 MCP tool 参数。Claude Code 作为分析大脑动态生成 pandas 扫描逻辑，helpers 封装每次都要写的样板代码。
